# Zadanie: Palindromy

Program zawiera funkcję `is_palindrome`, która sprawdza, czy podany tekst jest palindromem.

## Opis
Palindrom to słowo lub zdanie, które czyta się tak samo od lewej do prawej i od prawej do lewej.  
Przykłady: *kajak*, *potop*.

## Użycie
Przykład wywołania funkcji w Pythonie:

```python
print(is_palindrome("kajak"))   # True
print(is_palindrome("potop"))   # True
print(is_palindrome("kot"))     # False
