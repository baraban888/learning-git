# Wizytówka Alex Bahatiuk

Prosta strona wizytówkowa w HTML + CSS.

## Strony
- `o_mnie.html` – podstawowe informacje o mnie  
- `kontakt.html` – dane kontaktowe + formularz  
- `style.css` – wspólny styl dla wszystkich stron  

## Funkcje
- menu nawigacyjne (O mnie / Kontakt)  
- responsywny design (prosty i czytelny)  
- ikony (Font Awesome)  
- klikalny email i telefon  
- sekcja z social media w stopce
